# Simple ATM Machine 

A basic ATM machine simulation built using Java.

## Features

- Check account balance
- Deposit money
- Withdraw money
- Prevent withdrawal when the balance is insufficient
- Validate invalid menu choices
- Exit the ATM safely

## Concepts Used

- Java
- Scanner for user input
- do-while loop
- switch statement
- if-else conditions
- Variables and arithmetic operators
- Input validation

## How It Works

The program starts with an initial balance of Rs. 1000.00.

The user can choose from four options:

1. Check Balance
2. Deposit Money
3. Withdraw Money
4. Exit

The program continues running until the user chooses the Exit option.

## How to Run

1. Make sure Java is installed on your computer.
2. Open the terminal in the project folder.
3. Compile the program:

```bash
javac SimpleATM.java
